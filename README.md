# 🌤️ Aetheria - Weather App

A modern, minimal, and beautifully designed weather application built with Flutter. **Aetheria** provides real-time weather updates, forecasts, and interactive weather data with a sleek Glassmorphic UI.

---

## ✨ Features

- **Real-Time Weather Data:** Accurate current temperature, humidity, wind speed, and atmospheric conditions.
- **Hourly & Daily Forecasts:** Clear forecast breakdown for planning ahead.
- **Glassmorphism UI:** Stunning, responsive dynamic design powered by Material 3 guidelines.
- **Offline Storage:** Caches recent weather data for fast offline viewing.
- **Smooth Navigation:** Seamless screen transitions and clean route management.

---

## 🛠️ Tech Stack & Architecture

- **Framework:** [Flutter](https://flutter.dev/) (Dart)
- **State Management:** [Provider](https://pub.dev/packages/provider)
- **API Client:** [Dio](https://pub.dev/packages/dio) (RESTful API integration with OpenWeatherMap)
- **Routing:** [GoRouter](https://pub.dev/packages/gorouter)
- **Local Storage:** [Hive](https://pub.dev/packages/hive)
- **Animations:** [Rive](https://pub.dev/packages/rive)
